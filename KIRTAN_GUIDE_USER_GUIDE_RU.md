# Kīrtan Guide — краткая инструкция

**Kīrtan Guide** — веб-путеводитель по песеннику Śrī Chaitanya Sāraswat Maṭh. Он помогает найти песнь, читать шлоки в удобном виде, слушать доступные записи SoundCloud и использовать текст в режиме телесуфлёра.

## 1. Найдите нужную песнь

На главной странице используйте большое поле поиска: оно ищет по названию, автору, категории, первой строке и тексту песен. Результаты обновляются сразу, а совпавшие слова выделяются. При повторном фокусе на поиске доступны недавние запросы.

| Инструмент | Как использовать |
|---|---|
| **Author** | Показывает песни выбранного автора. |
| **Category** | Ограничивает библиотеку разделом песенника. |
| **Recording** | Выберите **With recordings**, чтобы увидеть только песни с доступной записью SoundCloud. |
| **Library** | Просматривайте песни по разделам; нажмите на число песен категории, чтобы раскрыть полный список. |
| **Index A–Z** | Переключитесь на алфавитный индекс по первой строке шлоки и используйте буквы для быстрого перехода. |

На карточке песни значок аудио и число рядом с ним означают, сколько записей доступно. Нажмите карточку, чтобы открыть страницу песни.

## 2. Читайте песнь

На странице песни автор и категория являются ссылками: они возвращают в библиотеку сразу с нужным фильтром. Ссылка **Listen** открывает компактный официальный плеер SoundCloud. Если у песни несколько вариантов, выберите нужный в списке **Recording**.

В верхнем правом углу статьи откройте **Reading Tools**. Компактная панель сохраняет выбранные настройки в браузере.

| Возможность | Действие |
|---|---|
| **Размер текста** | Используйте маленькую и большую `A` для уменьшения или увеличения шлок. |
| **Межстрочный интервал** | Кнопки с линиями делают текст плотнее или свободнее. |
| **Вторичные ornaments** | Кнопка со скобками скрывает или показывает фрагменты в круглых скобках, например `(kiba)`. |
| **Английский перевод** | Включите или выключите переводы всех шлок; отдельную шлоку можно раскрыть её номером. |
| **Второй язык** | Нажмите иконку языков и выберите русский, украинский, испанский, итальянский, китайский, тайский, португальский, хинди или бенгали. Второй перевод появляется под английским и отмечается контрастной вертикальной чертой. |
| **Поиск внутри песни** | Введите слово или фразу, затем переходите между совпадениями кнопками «назад/вперёд». |
| **Закладка и копирование** | Добавьте песнь в Favorites либо скопируйте её как **Plain Text** или **Markdown Text**. |

> Второй перевод создаётся из английского пояснения и сохраняется для повторного открытия. Имена и термины с IAST-диакритикой передаются в письменность выбранного языка; для латинских языков сохраняется канонический IAST.

## 3. Используйте Избранное и меню

Нажмите на логотип **Kīrtan Guide**, чтобы открыть меню. Отсюда можно быстро перейти в **Library**, к полю **Search** или в **Favorites**. В Favorites хранятся отмеченные песни; список остаётся в браузере после перезагрузки страницы.

## 4. Слушайте и синхронизируйте чтение

Песни с записью получают ссылку **Listen** и, при необходимости, выбор версии записи. Когда SoundCloud-плеер загрузил длительность трека, телесуфлёр может подстроить темп под неё. В панели темпа выберите **Match SoundCloud duration**, чтобы вернуть ползунок к рассчитанному значению.

Ручная настройка остаётся доступной всегда и сохраняется **отдельно** для Auto-scroll и Slideshow.

## 5. Режим телесуфлёра

Откройте телесуфлёр из Reading Tools. Он показывает только крупные шлоки с учётом размера текста, межстрочного интервала и настройки ornaments.

| Режим | Управление |
|---|---|
| **Auto-scroll** | Нажмите `Play`, чтобы текст плавно прокручивался. Кнопка скорости открывает ползунок с отметками **Slow**, **Steady** и **Fast**. Свайп или прокрутка, а также клавиши `↑` и `↓`, работают как перемотка и не ставят воспроизведение на паузу. |
| **Slideshow** | Каждая шлока показывается отдельной карточкой; до следующей строфы виден обратный отсчёт. Боковые кнопки на карточке и клавиши `←` / `→` листают шлоки, не прерывая автоматическое воспроизведение. |
| **Темп и пауза** | Во время работы рядом с `Pause` остаётся кнопка темпа, поэтому скорость можно менять без остановки. При запуске control rail сворачивается, чтобы не закрывать текст. |

## 6. Практический сценарий для совместного кīртана

Сначала найдите песнь по первой строке или автору. Если есть запись, откройте **Listen** и выберите нужную версию. В Reading Tools увеличьте текст, при необходимости скройте ornaments, включите перевод и выберите второй язык. Затем откройте телесуфлёр: для непрерывного чтения выберите **Auto-scroll**, а для показа строф группе — **Slideshow**. Если включена запись SoundCloud, используйте **Match SoundCloud duration** как отправную точку и при необходимости подстройте темп вручную.

## Полезные замечания

Настройки чтения, избранное, недавние поисковые запросы, выбранный второй язык и ручные темпы сохраняются локально в браузере. При очистке данных сайта эти персональные настройки могут быть сброшены. Для создания нового второго перевода требуется интернет-соединение; уже подготовленные варианты берутся из кэша.
