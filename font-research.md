# Font research — transliterated shlokas

## Selected family: Charis SIL

**Charis SIL** will replace the current display serif for transliterated shloka lines only. It retains a classical book-serif character suitable for the Pilgrim's Scroll reading surface while prioritizing extended Latin and combining-mark layout. The project will keep Cormorant Garamond for display headings and the Kīrtan Guide wordmark, so the editorial hierarchy remains intact.

SIL describes Charis as a Unicode-based family for Latin and Cyrillic scripts, designed for comfortable long-form reading on both low- and high-resolution displays. Its Google Fonts description notes smart font routines that position diacritics to optimize arbitrary base-plus-diacritic combinations. This directly addresses the combining candrabindu in `ā̐`.
